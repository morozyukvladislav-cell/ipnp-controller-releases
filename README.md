# IPNP Controller

Офіційні інсталятори та підписані оновлення програми **IPNP Controller by Morozyuk** для Windows.

У цьому репозиторії розміщуються лише готові випуски, інструкції та відомості про версії. Вихідного коду, службових документів і персональних даних тут немає.

## Завантаження

Готові файли публікуються на [сторінці випусків](https://github.com/morozyukvladislav-cell/ipnp-controller-releases/releases).

- **Setup.zip** — інсталятор та українська інструкція. Встановлює програму для поточного користувача й додає ярлик у меню «Пуск».
- **Windows.zip** — переносний EXE та інструкція для запуску без встановлення.
- **update.json** — підписані відомості для автоматичної перевірки оновлень у клієнті.

## Актуальна версія — 2.1.5

[Завантажити 2.1.5 та прочитати зміни](https://github.com/morozyukvladislav-cell/ipnp-controller-releases/releases/tag/v2.1.5).
Додано рівні підбору категорій, короткі списки варіантів із поясненнями,
локальну пам’ять ручних підтверджень та правило 307:2 → 31 у визначеному
контексті. У плані видно статтю з ІПНП; таблицю розширено, діагностику згорнуто.
Сім спірних правил залишаються ручними. Межі перевірки наведено в описі випуску.

## Оновлення — тимчасово ручне

Репозиторій наразі приватний. Увійдіть у GitHub обліковим записом із доступом
і завантажте Setup.exe або Setup.zip зі сторінки випуску. Завершіть поточну
чергу, закрийте контролер та запустіть інсталятор поверх наявної версії.
Налаштування та локальний журнал зберігаються; видаляти програмні дані не потрібно.

Поточний клієнт не авторизується в приватному GitHub-репозиторії, тому
вбудована перевірка оновлень тимчасово недоступна. Це не перериває локальну роботу.
Підписаний update.json зберігається для майбутнього відновлення відкритого каналу.
У клієнті немає вбудованих ключів доступу до GitHub.

## Вимоги

Windows 10 (1809 або новіша) / Windows 11, x64; Microsoft WebView2 Runtime для вікна клієнта. Якщо Runtime відсутній, інсталятор завантажує його з Microsoft. Python і Fiddler не потрібні.

Для роботи з ІПНП потрібні службовий доступ та авторизована вкладка Microsoft Edge у режимі Internet Explorer. Програма не надає доступу до ІПНП і не передає документи чи вміст карток на GitHub.
