# IPNP Controller

Офіційні інсталятори та підписані оновлення програми **IPNP Controller by Morozyuk** для Windows.

У цьому репозиторії розміщуються лише готові випуски, інструкції та відомості про версії. Вихідного коду, службових документів і персональних даних тут немає.

## Завантаження

Готові файли публікуються на [сторінці випусків](https://github.com/morozyukvladislav-cell/ipnp-controller-releases/releases).

- **Setup.zip** — інсталятор та українська інструкція. Встановлює програму для поточного користувача й додає ярлик у меню «Пуск».
- **Windows.zip** — переносний EXE та інструкція для запуску без встановлення.
- **update.json** — підписані відомості для автоматичної перевірки оновлень у клієнті.

## Актуальна версія — 2.1.11

[Випуск 2.1.11 та перелік змін](https://github.com/morozyukvladislav-cell/ipnp-controller-releases/releases/tag/v2.1.11).

- Підтвердження запиту без ПІБ більше не втрачається при повторній побудові плану: вибір і позначка відновлюються, а єдиний кандидат підставляється одразу разом із реквізитами картки.
- Програма більше не зупиняється, коли порт 8877 зайнятий: повідомлення про перехід на вільний порт більше не ламає консоль із некириличним кодуванням.
- Відхилений локальний запит більше не рве з'єднання — інтерфейс отримує саму відмову, а не помилку зв'язку.
- Повний набір перевірок виконується на кожну зміну на Python 3.12 і 3.13; саме він знайшов два дефекти вище.

Контрольного заповнення реальної картки для 2.1.11 не виконувалося: перевірте роботу на власній картці після встановлення.

## Оновлення через програму

Натисніть «Перевірити оновлення» у вікні клієнта, а після появи нової версії —
«Встановити». Програма завантажить пакет, перевірить його цифровий підпис
і контрольну суму та встановить оновлення після закриття клієнта.
Налаштування й локальний журнал зберігаються. Ручне завантаження з GitHub
та обліковий запис GitHub для оновлення не потрібні — достатньо інтернету.

Якщо кнопка ще показує «Оновлення недоступні · повторити», натисніть її знову:
публічний канал відновлено 10.09.2026. У клієнті немає вбудованих ключів GitHub.

## Вимоги

Windows 10 (1809 або новіша) / Windows 11, x64; Microsoft WebView2 Runtime для вікна клієнта. Якщо Runtime відсутній, інсталятор завантажує його з Microsoft. Python і Fiddler не потрібні.

Для роботи з ІПНП потрібні службовий доступ та авторизована вкладка Microsoft Edge у режимі Internet Explorer. Програма не надає доступу до ІПНП і не передає документи чи вміст карток на GitHub.
